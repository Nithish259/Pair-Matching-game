A fun and responsive memory card matching game built with HTML, CSS, and JavaScript.
Flip the cards, find matching pairs, and test your memory skills!

🎴 Dynamic card grid generated via JavaScript
🔀 Randomized card shuffle each round
✅ Match detection logic
💥 Win detection with alert and color animation
📱 Fully responsive — works on desktop, tablet, and mobile
🎨 Smooth animations and modern gradient design
🔁 Reset button to restart anytime

How to Play

1.Click on any two cards to flip them.

2.If both cards show the same image, they remain open (matched).

3.If not, both flip back automatically.

4.Continue until all pairs are matched.

5.When all pairs are found — 🎉 you win!
